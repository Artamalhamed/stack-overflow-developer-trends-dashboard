# Stack Overflow Developer Trends Dashboard

This project was completed as part of the IBM Data Analyst Professional Certificate.

## Project Overview

The project analyzes Stack Overflow Developer Survey data to identify current and future technology trends. The analysis focuses on programming languages, databases, platforms, web frameworks, job postings, and respondent demographics.

## Objectives

* Identify the top programming languages currently used by developers.
* Compare current technology usage with technologies desired for the next year.
* Analyze database trends and future demand.
* Explore respondent demographics such as age, country, and education level.
* Present insights using dashboards and visualizations.

## Key Findings

* JavaScript, SQL, TypeScript, HTML/CSS, and Python appeared among the top programming languages.
* PostgreSQL was the leading database in both current usage and next-year interest.
* Cloud platforms such as AWS, Microsoft Azure, and Google Cloud appeared as important technologies.
* Most respondents were in the 25–34 age group.
* Dashboards helped summarize technology trends and demographic insights clearly.
